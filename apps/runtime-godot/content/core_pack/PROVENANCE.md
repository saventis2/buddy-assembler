## Promotion procedure

To promote a snapshot of `core_pack` to shipping:

1. Run the character/emote export pipeline and verify output in
   `content/core_pack/character/` and `content/core_pack/character/emotes/`.
2. Update `manifest.json` version field (semver bump).
3. Update this file: set **Approved** date and sign off under **Approver**.
4. Open a PR targeting main. CI `validate-content` must pass.
5. Merge. SHA256SUMS generated by CI include all pack assets.

No WZ/NX or other proprietary binary files may be committed at any stage.
